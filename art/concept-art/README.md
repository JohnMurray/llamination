# Character unit mockups

Transparent concept renderings for the six character units currently defined in
`docs/characters.md`. The set uses a shared late-1990s pre-rendered RTS direction:
slightly downsampled edges, hand-painted surface detail, teal woven accents, worn
brown leather, and warm upper-left lighting.

| Asset | Unit role |
| --- | --- |
| `llama.png` | General-purpose village unit |
| `golden-retriever.png` | Resource-carrying support companion |
| `corgi.png` | Versatile advanced military unit |
| `dachshund.png` | Burrowing advanced military unit |
| `beaver.png` | Waterworks engineering unit |
| `groundhog.png` | Terrain engineering unit |

These are high-resolution visual-development mockups rather than production
spritesheets. They are isolated on transparent backgrounds so they can also be
used in unit cards, menus, and future sprite-generation references.
